    // ─── Фасеты вентиляции (25.08.2026) ────────────────────────────────────────
    // Одно описание на фильтр: отсюда берут и счётчики, и фильтрация, и панель.
    // Фильтр показывается, только если данных хватает — не меньше 10 позиций
    // и не меньше двух разных значений. Иначе фильтр обещает выбор, которого нет.
    // Отдельного фильтра «Тип оборудования» нет намеренно: поле `t` один в один
    // повторяет подкатегорию, а она уже выбирается выше. Один признак — один орган.
    const specOf = (x, re) => {
      const row = (x.sp || []).find(v => re.test(String(v[0])));
      return row ? String(row[1] || "").trim() : "";

    //    и поиск «первой подходящей строки» читал амперы вместо вольт — 156 позиций
    //    вместо 409. Поэтому «Электропитание» спрашиваем отдельно и первым;
    //  · значение записано как «230,1,50» и «380,3,50» — это вольты, фазы, герцы.
    //    Ловить «380» подстрокой ненадёжно, берём первое число как напряжение.

    // Очистка воздуха: в мастере пять написаний, из них «нет» и «уточнить» — это

    // что-то утверждают, и подписаны они словами покупателя, а не значением ячейки.
